Sources et méthode

Archi-bon privilégie les sources de protection animale et les références vétérinaires.

Comment Archi-bon décide ?

  1. La base locale est prioritaire pour les fiches déjà vérifiées.
  2. L'absence d'une plante dans la base ne signifie jamais qu'elle est sûre.
  3. L'IA ne peut proposer un statut que si des éléments suffisamment directs ont été trouvés dans les sources consultées.
  4. Une identification ambiguë ou une preuve insuffisante reste ⚪ À VÉRIFIER.
  5. Les sources sont affichées pour que tu puisses les consulter directement.
